# 《微光归处》WeGame 商店页文案

> 平台：WeGame（腾讯国区 PC 客户端）
> 游戏类型：叙事 / 解谜 / 休闲（Unity 2D URP，桌面构建已绿）
> 中文标题：**《微光归处》**
> 定位：对标国内 PC 玩家，强调「慢节奏治愈」与「碎片时间友好」

---

## 1. 简介
《微光归处》是一款安静的治愈叙事解谜。你守着一间收留旧念想的小铺，替客人拂去旧物上的尘，听它们低语，拼回碎掉的此刻，为每段记忆选一个结局，再收进图鉴。五段委托、十三枚碎片、十一种结局，没有战斗、没有失败、没有催促——只等你慢下来，把光轻轻放回原处。

## 2. 卖点（≥5）
1. **四动词温柔循环**：拂尘显影 → 拼合复原 → 抉择分支 → 图鉴归档，一个闭环几分钟，拿起就走。
2. **五件有故事的旧物**：停摆的怀表、褪色的全家福、未寄出的信、断裂的银簪、蒙尘的梳妆镜，每件都替谁守着从前。
3. **选择即归处**：每个抉择落向「真述 / 藏起 / 改写」三种情绪结局，≥10 种收场，多周目收集图鉴。
4. **为碎片时间而生**：单段委托约 6–10 分钟，鼠标 / 触控板即可操作，通勤与睡前的间隙都能玩。
5. **低配也流畅**：自动下调拂尘分辨率与降采样，老机器、核显本也能安稳运行。
6. **全年龄温和向**：内容无暴力色情，节奏舒缓，适合想要「被旧物故事打动」的任何人。

## 3. 配置要求（最低 / 推荐）
**最低配置：**
- 操作系统：Windows 10 64 位
- 处理器：Intel Core i3 或同等
- 内存：4 GB RAM
- 显卡：集成显卡（Intel HD 4000 及以上）
- 存储空间：1 GB 可用空间
- 备注：鼠标 / 触控板操作；低内存机自动降画质保流畅

**推荐配置：**
- 操作系统：Windows 11 64 位
- 处理器：Intel Core i5 或同等
- 内存：8 GB RAM
- 显卡：独立显卡
- 存储空间：2 GB 可用空间

## 4. 适龄提示
- **适龄分级**：建议 **12+**（内容全年龄向、无暴力色情与恐怖元素；基于情绪主题轻微怅惘，建议低龄玩家在家长陪同下游玩）。
- **未成年人保护**：正式上架将按版号与未成年人保护合规要求，配置适龄提示与防沉迷机制（健康游戏忠告、时长与消费限制以平台与版号要求为准）。
- **健康游戏忠告**：抵制不良游戏，拒绝盗版游戏；适度游戏益脑，沉迷游戏伤身；合理安排时间，享受健康生活。
