## 一、整体规格与技术提示
- **分辨率 / 帧率**：1080×1920，30fps，H.264，竖版。
- **安全区**：标题与字幕落在中央 90% 区域，底部 1/5 留给标语 / CTA；图标、Logo 不被圆角/刘海裁切。
- **色彩**：暖琥珀微光（拂尘渗光、铺子门缝）对比冷灰尘蒙（蒙尘态），显影时暖光渐起。
- **BGM**：低频环境垫底 + 收尾上行五度（基调温柔悬疑）；无歌词。
- **SFX**：尘埃细碎声（拂尘）、碎片吸附咔哒（拼合）、纸签轻响（抉择）、柔光收束（归档）。
- **字幕字体**：思源宋体 / 系统衬线，浅色描边，避免与暖光抢视线。

## 三、可分镜细节备注（给美术 / 剪辑）
- **S3 拂尘**：尘遮罩透明度随指尖轨迹下降，微光以尘埃粒子渗出的方式渐显；保持「慢」的呼吸感，不疾不徐。
- **S4 拼合**：碎片吸附带轻微磁吸缓动；重圆刹那微光一闪（与 S3 同色温）。
- **S5 抉择**：两枚纸签分列左右，选中的一枚暖光铺满、未选的悄然淡出，对应结局卡色调（真述=释然暖、藏起=怅惘冷）。
- **S6 归档**：图鉴时间线以「光点连线」生长；五物件快剪各 0.8s，节奏由慢到稳。
- **S7 CTA**：标语用平台实际可搜关键词；若多平台分发，按渠道替换（TapTap / Steam / WeGame）。
