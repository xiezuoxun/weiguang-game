## 1. 标题
**《微光归处》**

## 2. 一句话简介
拂去旧物上的尘，把藏在里面的微光，轻轻放回原处。

## 3. 标签（≥8）
治愈 · 叙事解谜 · 单元剧 · 竖屏 · 全手势 · 单机 · 怀旧 · 国风 · 慢节奏 · 剧情向 · 2D · 独立游戏
（共 12 个，上架后台按需勾选，建议主推：治愈 / 叙事解谜 / 竖屏 / 单机）

## 4. 特色卖点（5 条）
1. **四动词循环**：拂尘显影 → 拼合复原 → 抉择分支 → 图鉴归档，一个完整循环只要几分钟，拿起就走、放下也安心。
2. **五段旧物委托**：停摆的怀表、褪色的全家福、未寄出的信、断裂的银簪、蒙尘的梳妆镜——每件都为谁守着一段从前。
3. **选择落定归处**：每个抉择通向「真述 / 藏起 / 改写」三种情绪结局，≥10 种收场，你的手温柔地改变故事。
4. **为碎片时间而生**：竖屏全手势操作，单段委托约 6–10 分钟，通勤、睡前、等一杯茶的间隙都能玩。
5. **温柔不催促**：无战斗、无失败、无日常强制任务；低端机自动降画质保流畅，慢一点也很好。

## 6. FAQ（≥5）
**Q1：这是什么类型的游戏？有战斗吗？**
A：治愈向叙事 + 单元剧解谜。没有战斗、没有失败惩罚、没有日常强制任务。你只需用指尖拂去旧物上的尘，听它们说话，替它们选一个去处。

**Q2：一次要玩多久？适合碎片时间吗？**
A：非常适合。游戏为竖屏全手势设计，单段委托（一个完整四动词循环）约 6–10 分钟，随时拿起、随时放下，进度自动本地存档。

**Q3：必须联网或注册账号吗？**
A：本体以单机体验为主，无需强制联网或注册。存档保存在本机，切后台可精确恢复（见 `SaveEngine` 原子写 + 校验和）。

**Q4：支持哪些设备？老手机会卡吗？**
A：安卓 / iOS 均可。针对低内存机型做了降级策略——自动封顶拂尘网格分辨率与降采样，保证流畅；桌面/高内存设备保持更高画质。如仍遇到掉帧，欢迎在测试招募中反馈机型。

**Q5：付费 / 内购是怎么设计的？**
A：首发定价策略以实际上架页公示为准（买断或免费试玩二选一，确定后回填）。设计原则：无随机抽卡、无数值付费、无诱导性弹窗；所有情感内容均可凭操作解锁，不卖数值。

**Q6：有哪些结局？会剧透吗？**
A：5 段委托对应 11 个结局卡，按情绪分为「真述 / 藏起 / 改写」三向（释然 / 怅惘 / Reframe）。同一委托的不同选择会落向不同归处，鼓励多周目收集图鉴，但不强制。

**Q7：未成年人可以玩吗？**
A：游戏内容温和、全年龄向，无暴力色情。正式上架将按版号与未成年人保护合规要求配置适龄提示与防沉迷（详见 `phase8-release-checklist.md` 合规项）。

**Q8：只有中文吗？会做其他语言吗？**
A：首发以简体中文为主。英文标题统一为 **Glimmer's Rest**；多语言本地化视后续运营规划推进，以公告为准。
