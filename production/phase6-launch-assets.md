## 2. 短视频脚本：30s 竖版（9:16，建议 1080×1920）

核心循环四镜，旁白文案复用 OnboardingHints 四动词：**拂尘 → 拼合 → 抉择 → 归档**。

| 镜 | 秒数 | 画面 | 旁白（中文） | 字幕钩子 |
|----|------|------|--------------|----------|
| 1 拂尘 | 0–8s | 怀表蒙尘，指尖轻拂，微光自尘隙渗出（R8 尘遮罩 Shader） | 「轻拂去尘，旧物里藏着的微光就醒了。」 | 拂尘·显影 |
| 2 拼合 | 8–16s | 碎片 `fr_*` 沿 anchor 吸附入槽，物件重圆（S2 拼合） | 「把碎掉的此刻，一块块拼回原样。」 | 拼合·复原 |
| 3 抉择 | 16–24s | 纸签两 option 浮现，玩家点选（S3 单层），结局微变 | 「留给它一个结局——你怎么选，它由你。」 | 抉择·分支 |
| 4 归档 | 24–30s | 物件入图鉴，时间线添一笔，柔光收束 | 「收进图鉴，这段光就归到它该在的地方。」 | 归档·安放 |

- BGM：低频环境 + 收尾上行五度（基调温柔悬疑）。
- 字幕全角 ≤18 字/行（对齐 `whispers.csv` 长度约束 CR-001 R7）。
- 结尾 CTA：TapTap/微信搜索「微光归处」。

## 4. 字段对齐说明（素材命名 ↔ CSV，避免生产错位）

> 美术/运营产出的位图与视频内出现的物件，命名须能回溯到 CSV 主键，方便程序侧按 `item_id` 取图、按 `fragment_id` 取碎片贴图。

**物件（items.csv → item_id）**
| item_id | 物件 | 素材命名建议 |
|---------|------|--------------|
| it_watch | 停摆的怀表 | `art_item_it_watch.png`（+ `_icon` / `_promo`） |
| it_photo | 褪色的全家福 | `art_item_it_photo.png` |
| it_letter | 未寄出的信 | `art_item_it_letter.png` |
| it_ornament | 断裂的银簪 | `art_item_it_ornament.png` |
| it_mirror | 蒙尘的梳妆镜 | `art_item_it_mirror.png` |

**碎片（fragments.csv → fragment_id，13 片，按 item_id 归组）**
- it_watch：`fr_001`
- it_photo：`fr_002` `fr_003`
- it_letter：`fr_004` `fr_005`
- it_ornament：`fr_006`~`fr_009`
- it_mirror：`fr_010`~`fr_013`
- 碎片贴图命名：`art_frag_<fragment_id>.png`，其 `slot_index`/`anchor_x`/`anchor_y` 已由 `fragments.csv` 给定，拼合镜头严格按表摆放。

**结局（endings.csv → ending_id，11 行，按 commission_id 归组）**
- com_001：`en_001` `en_002`；com_002：`en_003`~`en_005`；com_003：`en_006` `en_007`
- com_004：`en_008` `en_009`；com_005：`en_010` `en_011`
- 结局卡面命名：`art_ending_<ending_id>.png`，`ending_tag` ∈ {Truth, Omit, Reframe} 决定色调（释然/怅惘/Reframe）。

**对齐红线（错则契约 FAIL 或运行时丢图）**
1. 任一 `art_item_*` 必须存在对应 `item_id`，反之亦然；下架物件须同步删 CSV 行。
2. 碎片贴图数必须 == 该物件 `fragment_count`（即 R4 交叉校验，CI 会拦）。
3. 结局卡面 `ending_tag` 须与 `endings.csv` 同 `commission_id` 下的取值一致（R5 一致性）。

## 5. 沙箱不可验 / 需本机或美术侧交付的项

- 上述所有位图（1024×500 / 512×512 / 16:9）与 30s 视频：需美术在本机用 PS/AE/Blender 产出，沙箱无二进制能力。
- 圆角 22.5% 实际渲染效果、BGM 混音：需美术/音频侧确认。
- 设备档位问卷表单（微信/QQ/TapTap 落地页）：需运营侧在对应平台建表并回填。
- CSV 存量 BOM：当前 `commissions.csv` / `items.csv` 带 BOM（仅 warn 不阻断），建议美术/内容侧另存为 UTF-8 无 BOM，消除告警噪声。
